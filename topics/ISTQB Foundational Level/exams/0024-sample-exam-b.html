Sample Exam B — generate it with Claude

The official ISTQB® CTFL v4.0 Sample Exam Set B is a complete 40-question paper. A full copy of an ISTQB® document goes beyond the non-commercial extracts that ISTQB® permits, so it isn't published in this repository — but you can build the same interactive, timed exam page for yourself in a couple of minutes with Claude Code and the istqb-prep skill.

What you'll get: all 40 Set B questions in their original order, in the same exam mode as the four mock exams — timer, Submit Exam to grade everything at once, the official correct answers and justifications, and a per-chapter score breakdown. Set B already follows the CTFL v4.0 blueprint (8/6/4/11/9/2), and none of its questions appear in the mock exams, so it's a clean final check.

1. Download the official PDFs

Get ISTQB® CTFL v4.0 Sample Exam B — Questions and Answers (v1.7 or later) free from the official ISTQB® CTFL v4.0 page.

2. Put them in the cache folder

Save both PDFs into cache/ISTQB/Foundational/ at the root of this repository. That folder is git-ignored, so the PDFs never get committed.

3. Ask Claude to build the page

Open Claude Code in the repository root and paste this prompt (adjust the file names if your version differs from v1.7):

Using the istqb-prep skill, build a standalone exam page for the official ISTQB CTFL v4.0 Sample Exam B.

Sources: cache/ISTQB/Foundational/ISTQB_CTFL_v4.0_Sample-Exam-B-Questions_v1.7.pdf and ISTQB_CTFL_v4.0_Sample-Exam-B-Answers_v1.7.pdf (extract them as described in references/source-extraction.md).

Output: topics/ISTQB Foundational Level/exams/0024-sample-exam-b.local.html in exam mode per references/exam-html-contract.md, styled like exams/0023-final-mock-exam-4.html (same crumbs, submit bar, timer, results breakdown, ../assets/exam.js).

Content: all 40 questions verbatim in their original order. Tag each one "Exam B · Q<n> · <LO code> · <K-level>" from the Answer Key, use the Answer Key's correct answers and per-option justifications as the rationale, and keep "select TWO" questions as multi-select.

Footer: include the footer.istqb-notice crediting the ISTQB CTFL Syllabus v4.0.1 and Sample Exam B v1.7 (Questions & Answers).

This page is for my local study only. Do not commit it.

4. Open your exam

Claude writes exams/0024-sample-exam-b.local.html. Once it exists: Open Sample Exam B → (if the link doesn't open, the page hasn't been generated yet).

Keep it local. The generated page is a full copy of an ISTQB® document — for your own non-commercial study only. *.local.html files are git-ignored in this repository; don't commit, publish or share the generated page.
